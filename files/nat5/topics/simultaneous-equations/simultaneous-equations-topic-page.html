          Starter

          Think of two numbers

          Two numbers add to 31. Their difference is 7. What are they?

          Two numbers add to 20. Three times the first plus the second is 44. What are they?

          Extra: make up a puzzle like this for a partner. Can you make one where the answers are negative?

          Answer19 and 12 (add the equations: 2a = 38). 12 and 8 (subtract: 2a = 24).
          Spot the mistake

          What went wrong?

          Hamish solves 3x + 2y = 16 and x − 2y = 0.

          He subtracts: 2x = 16
          so x = 8 and y = 4

          Find his mistake, then solve it properly. How could he have spotted it himself?

          AnswerThe y terms have opposite signs (+2y and −2y), so he should add: 4x = 16, x = 4, y = 2. Checking in the first equation would show it: 3(8) + 2(4) = 32, not 16.
          Which method?

          Pick the best method

          For each pair, say which method you would use and why. Then solve one.

          A: 4x + y = 14, 2x − y = 4
          B: y = 2x − 1, 3x + 2y = 19
          C: 3x + 2y = 12, 2x + 5y = 19
          D: 5x + 3y = 21, 5x + y = 17
          AnswerA: add (opposite signs on y), x = 3, y = 2. B: substitution (y = … already), x = 3, y = 5. C: multiply both (×2 and ×3 to match x), x = 2, y = 3. D: subtract (same signs on 5x), x = 3, y = 2.
          Think about it

          No answer, or every answer?

          Try to solve 2x + y = 3 and 2x + y = 5. What happens? Now try x + y = 4 and 2x + 2y = 8.

          Sketch each pair of lines. What does this tell you about the lines?

          AnswerThe first pair gives 0 = 2, which is impossible: the lines are parallel and never cross, so there is no solution. The second pair gives 0 = 0: it is the same line twice, so every point on it is a solution.
          Challenge

          Find a and b

          The line ax + by = 13 passes through the points (2, 3) and (5, 1). Find a and b.

          Extra: find the equation of the line through (1, 7) and (4, −2) in the form y = mx + c.

          Answer2a + 3b = 13 and 5a + b = 13, so a = 2, b = 3: 2x + 3y = 13. Extra: m + c = 7 and 4m + c = −2, so m = −3, c = 10: y = −3x + 10.
